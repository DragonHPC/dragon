# Security Policy

## Purpose & Regulatory Compliance

DragonHPC is committed to ensuring the security and resilience of our open source software.
We have adopted this security disclosure and response policy to ensure we responsibly handle
critical security issues and regulatory compliance in a timely manner.

## Supported Versions

Only the latest major release version of DragonHPC is actively supported
with security patches. Users are strongly encouraged to upgrade to the latest
stable release to ensure they receive critical security fixes. Review our release
notes regarding recent releases.

## Reporting a Vulnerability

Do not open a public GitHub issue for security bugs or potential vulnerabilities.

To report a vulnerability affecting DragonHPC please email dragonhpc@hpe.com.

**Information to Include:**
   * A detailed description and context for the vulnerability.
   * Steps, scripts, or minimal code needed to reproduce the issue.
   * Potential impact on other software.

## Response & Disclosure Timeline

* **Acknowledgement:** The DragonHPC team will acknowledge receipt of your report
within 48 business hours.
* **Coordination:** The DragonHPC team will work with developers and any other needed teams
to validate and resolve the security vulnerability.
* **Security Incidents:** If the vulnerability is found to be actively exploited
in the wild or has resulted in a significant security incident, DragonHPC will notify relevant cybersecurity
coordinators within 24 hours of confirmation with a detailed followup within 72 hours.
* **Fix & Release:** Security advisories and patches will be published natively
through our GitHub repository.
